登录请求接口：
```shell
curl --location --request POST '127.0.0.1:8080/front/user/login?phone&password&type' \
--header 'Content-Type: application/json' \
--data-raw '{
"phone": "string",
"password": "string",
"type": "1"
}'
```
响应1
```json
{
    "code": 200,
    "message": "登陆成功",
    "data": {
        "Authorization": "1_75deea35-7b20-420b-b87e-193388cc7fff",
        "phone": "15688463267",
        "userName": "admin",
        "userId": 1
    }
}
```
响应2
```json
{
    "code": 202,
    "message": "用户名或密码错误",
    "data": null
}
```




验证token是否过期接口：
```shell
curl --location --request POST '127.0.0.1:8080/front/user/checkToken?token'
```

未过期返回 true
过期返回 false

退出登录接口：
```shell
curl --location --request GET '127.0.0.1:8080/front/user/logOut'
```

---


1. 用户访问受保护页面 → 路由守卫检查 token → 验证有效性 → 放行/重定向
2. 用户登录 → 调用登录接口 → 保存 token 和用户信息 → 跳转到主页
3. 用户退出 → 确认 → 调用退出接口 → 清除数据 → 返回登录页

所有代码都包含了详细的中文注释，遵循项目现有的代码规范！
